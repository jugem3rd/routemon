# Routemon Community v0.1.0

> GitHub Releaseのnotesの下書き。tag `v0.1.0`を打つ前に、#4の通し確認の結果を反映する。

YAMAHAルーターをまとめて管理するセルフホスト型の管理基盤、Routemon Communityの最初のreleaseです。

## 導入

DockerとDocker Composeが入ったLinux(VPS等)で、次の2行で起動します。

```sh
curl -fsSLO https://raw.githubusercontent.com/jugem3rd/routemon/main/compose.yaml
docker compose up -d
```

Browserで`http://<server-ip>:8080/`を開き、Setup Wizardで次を設定します。

1. Instance名とTimezone
2. 最初の管理者
3. Public URL(RouterからOutbound HTTPSで届くURL)
4. 接続確認

その後、GUIの`Devices`から`Deviceを追加`を押し、表示された2行のCLI blockをルーターのコンソールへ貼り付けます。

imageは`ghcr.io/jugem3rd/routemon`(`linux/amd64`、`linux/arm64`)です。`ROUTEMON_VERSION=0.1.0`で版を固定できます。更新は`docker compose pull && docker compose up -d`です。

## 主な機能

- Device Enrollment(CLI blockをルーターへ貼るだけでAgentが動く)
- 状態確認、コマンド実行
- SYSLOGの保存とLive Logs
- CONFIGの世代管理、差分、復元
- YAMAHA Native WebGUIの中継(Adminのみ)
- Agentの更新(A/B方式、rollback付き)
- Local Auth、RBAC、監査ログ
- Backup / Restore

## 対応機種

- 動作確認済み: RTX830(Rev.15.02.30)
- それ以外の機種(RTX1210、RTX1220、NVR等)は未確認です(確認は #9 で進めます)

## 既知の制限

- ルーターから、ServerのPublic URLへ、HTTPS(信頼された証明書、ドメイン、443)で届く必要があります
- `git clone`して`npm ci`で動かす方法は、開発者向けで、サポート外です
- Agentのrelease channelとstaged rolloutは未実装です
